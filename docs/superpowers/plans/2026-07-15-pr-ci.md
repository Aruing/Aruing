# Pull Request CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reproducible GitHub Actions quality gate for pull requests and pushes to `main`, with matching local Makefile commands.

**Architecture:** One workflow runs three independent jobs for build/tests, lint, and vulnerability scanning. The Makefile owns the executable commands, while `.golangci.yml` owns lint policy and the workflow owns event triggering, permissions, concurrency, and tool installation.

**Tech Stack:** GNU Make-compatible Makefile, Go 1.24.4, golangci-lint v2.12.2, govulncheck v1.1.4, GitHub Actions.

### Task 1: Add local quality commands

**Files:**
- Modify: `Makefile`

- [ ] **Step 1: Verify the new CI target does not exist**

Run: `make test-ci`

Expected: FAIL with `No rule to make target 'test-ci'`.

- [ ] **Step 2: Add overridable tool variables and quality targets**

Add these variables after the existing application variables:

```makefile
GO ?= go
GOLANGCI_LINT ?= golangci-lint
GOVULNCHECK ?= govulncheck
GO_PACKAGES := ./...
GO_SOURCE_DIRS := cmd internal
```

Replace the build section's phony declaration and targets with:

```makefile
.PHONY: build test test-ci fmt fmt-check vet lint lint-fix tidy-check vuln check clean

build:
	@mkdir -p "$(BIN_DIR)"
	$(GO) build -o "$(BIN)" $(CMD)

test:
	$(GO) test $(GO_PACKAGES)

test-ci:
	$(GO) test -race -shuffle=on -count=1 $(GO_PACKAGES)

fmt:
	gofmt -w $(GO_SOURCE_DIRS)

fmt-check:
	@files="$$(gofmt -l $(GO_SOURCE_DIRS))"; \
	if [ -n "$$files" ]; then \
		echo "$$files"; \
		exit 1; \
	fi

vet:
	$(GO) vet $(GO_PACKAGES)

lint:
	$(GOLANGCI_LINT) run $(GO_PACKAGES)

lint-fix:
	$(GOLANGCI_LINT) run --fix $(GO_PACKAGES)

tidy-check:
	$(GO) mod tidy
	git diff --exit-code -- go.mod go.sum
	@files="$$(git ls-files --others --exclude-standard -- go.mod go.sum)"; \
	if [ -n "$$files" ]; then \
		echo "$$files"; \
		exit 1; \
	fi

vuln:
	$(GOVULNCHECK) $(GO_PACKAGES)

check: tidy-check build test-ci fmt-check vet lint vuln

clean:
	rm -rf "$(BIN_DIR)"
```

- [ ] **Step 3: Run the Makefile checks that require no new tools**

Run: `make tidy-check build test-ci fmt-check vet`

Expected: PASS; all Go packages compile, tests pass with the race detector, and no formatting or vet issues are reported.

- [ ] **Step 4: Commit the Makefile targets**

```bash
git add Makefile
git commit -m "build: add Go quality check targets"
```

### Task 2: Define lint policy

**Files:**
- Create: `.golangci.yml`

- [ ] **Step 1: Verify the repository has no lint configuration**

Run: `test -f .golangci.yml`

Expected: FAIL with exit status 1.

- [ ] **Step 2: Create the golangci-lint v2 configuration**

Create `.golangci.yml` with:

```yaml
version: "2"

run:
  modules-download-mode: readonly

linters:
  default: none
  enable:
    - bodyclose
    - errcheck
    - govet
    - ineffassign
    - misspell
    - staticcheck
    - unused
    - wastedassign
    - whitespace
  settings:
    govet:
      enable:
        - shadow
  exclusions:
    generated: lax
    presets:
      - comments
      - common-false-positives
      - legacy
      - std-error-handling
    paths:
      - third_party$
      - builtin$
      - examples$

formatters:
  enable:
    - gofmt
  exclusions:
    generated: lax
    paths:
      - third_party$
      - builtin$
      - examples$
```

- [ ] **Step 3: Validate the configuration and lint the repository**

Run: `golangci-lint config verify && make lint && make fmt-check`

Expected: PASS with no lint or formatting findings.

- [ ] **Step 4: Commit the lint policy**

```bash

```

### Task 3: Add the GitHub Actions workflow

**Files:**
- Create: `.github/workflows/pr-check.yml`

- [ ] **Step 1: Verify the workflow does not exist**

Run: `test -f .github/workflows/pr-check.yml`

Expected: FAIL with exit status 1.

- [ ] **Step 2: Create the pull request workflow**

Create `.github/workflows/pr-check.yml` with:

```yaml
name: PR checks

on:
  pull_request:
    types: [opened, synchronize, reopened, ready_for_review]
  push:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build-test:
    name: Build and test
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - name: Check out repository
        uses: actions/checkout@v7
      - name: Set up Go
        uses: actions/setup-go@v6
        with:
          go-version-file: go.mod
          cache: false
      - name: Check module files
        run: make tidy-check
      - name: Build CLI
        run: make build
      - name: Run tests
        run: make test-ci

  lint:
    name: Lint
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - name: Check out repository
        uses: actions/checkout@v7
      - name: Set up Go
        uses: actions/setup-go@v6
        with:
          go-version-file: go.mod
          cache: false
      - name: Check formatting
        run: make fmt-check
      - name: Run go vet
        run: make vet
      - name: Run golangci-lint
        uses: golangci/golangci-lint-action@v9
        with:
          version: v2.12.2

  security:
    name: Vulnerability scan
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - name: Check out repository
        uses: actions/checkout@v7
      - name: Set up Go
        uses: actions/setup-go@v6
        with:
          go-version-file: go.mod
          cache: false
      - name: Install govulncheck
        run: |
          go install golang.org/x/vuln/cmd/govulncheck@v1.1.4
          echo "$(go env GOPATH)/bin" >> "$GITHUB_PATH"
      - name: Scan for reachable vulnerabilities
        run: make vuln
```

- [ ] **Step 3: Validate workflow syntax**

Run: `go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.12 .github/workflows/pr-check.yml`

Expected: PASS with no output.
